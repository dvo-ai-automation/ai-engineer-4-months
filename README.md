# AI Engineer in 4 maanden

Werkmap voor het traject van nul naar hireable AI engineer, 30 juli – 18 november 2026,
bij 15–25 uur per week.

## Waar staat wat

| Pad | Inhoud |
|---|---|
| [ROADMAP.md](ROADMAP.md) | Het volledige plan: 4 maanden, per skill, met picks, build targets en afvinkbare milestones |
| [prompts/](prompts/) | De drie prompts uit het artikel, letterlijk overgenomen |
| [maand-1-fundament/](maand-1-fundament/) | Python, Git, terminal, API's, SQL |
| [maand-2-llm-apis/](maand-2-llm-apis/) | Prompting, structured outputs, tool calling, streaming |
| [maand-3-rag-agents/](maand-3-rag-agents/) | RAG, vector-DB's, agents, evals |
| [maand-4-ship-it/](maand-4-ship-it/) | Deployment, portfolio, baan |
| [notities/](notities/) | Losse aantekeningen, vragen, dingen om later uit te zoeken |

Elk `projecten/`-mapje bevat de builds van die maand. Elk project krijgt een eigen map met
een eigen README.

## De twee regels waar alles op rust

1. **De 30-minutenregel** — per uur kijken/lezen minstens 30 minuten bouwen zonder tutorial open.
2. **Alles gaat publiek** — elk project op GitHub op de dag dat je het af hebt, ook de lelijke.
